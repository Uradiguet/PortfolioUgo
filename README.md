# Portfolio Ugo Radiguet — refonte 2026

Site statique prêt pour GitHub Pages. Ouvrir `index.html` ou servir le dossier avec `python3 -m http.server 8000`.

## Design

- Couleurs : `#363537`, `#0CCE6B`, `#DCED31`, `#EF2D56`, `#ED7D3A`.
- Titres : Megrim ; texte et interface : Josefin Sans.
- Accueil responsive avec filtres de projets, navigation mobile, parcours, compétences et contact direct.
- Les pages de détail des projets restent accessibles dans `SavoirPlus/` et conservent leurs médias.

## Publication sur GitHub Pages

Copier le contenu de ce dossier à la racine du dépôt `PortfolioUgo`, puis publier la branche via GitHub Pages. Les chemins relatifs fonctionnent dans `/PortfolioUgo/`.

Le bouton de contact ouvre le client e-mail de la personne qui visite le site. Les polices sont chargées depuis Google Fonts ; une police système prend le relais si elles sont indisponibles.
